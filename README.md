## 💻 Running Locally

To run this portfolio locally without any external dependencies:

```bash
# Clone the repository
git clone https://github.com/SauodAzad/My-portfolio.git

# Navigate to project directory
cd My-portfolio

# Start the built-in local server
node server.js
```

Open your browser and navigate to:
```
http://127.0.0.1:3000/
```

Or simply open `index.html` directly in any web browser.
